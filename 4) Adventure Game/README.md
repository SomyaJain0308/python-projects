# 04 — Choose Your Own Adventure Game

> **Note:** This project was skipped as a standalone build. The core concept — branching narrative logic using nested `if/elif/else` statements and input loops — was already fully implemented in [Project 01 (Quiz Game)](../01-quiz-game). Building it again would be redundant.

## The Concept

The program presents a scenario and asks the user to make a choice. Each choice leads to a new prompt, creating a tree of possibilities where the user wins or loses based on their decisions.

## What This Project Teaches

- Nested `if`, `elif`, `else` branching
- Multi-layered conditional flow
- Input handling for story-driven navigation

## Why Project 01 Covers This

The Quiz Game already implements:
- Branching paths based on user input (`shows` vs `movies`)
- Multiple layers of nested decisions
- Input validation loops at each decision point
- Different outcomes depending on the path taken

Same pattern, different story.
